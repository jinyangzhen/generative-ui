# Generative UI

A local-first project for exploring generative user interfaces.

## Overview

Generative UI experiments with interfaces that are composed, adapted, or produced dynamically rather than hand-coded screen by screen.

## Status

Early setup. Project structure and delivery workflow will evolve as work begins.

## Getting started

This repository is managed through Firstmate as a local-only project. Implementation work runs in isolated copies; the main branch here stays the landing point for approved changes.
